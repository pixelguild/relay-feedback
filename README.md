## About

Relay is a focused macOS REST client for developers who want speed, clarity, and zero bloat. It handles HTTP requests, collections, and code generation — and nothing else.

### Key Features

- **HTTP Methods** — GET, POST, PUT, DELETE, PATCH with a clean URL bar and instant send
- **Rich Response Rendering** — JSON tree view, XML, HTML preview, PDF, images, Office documents
- **Collection Management** — Nested folders, drag-and-drop, file-based and git-friendly storage
- **Variables & Environments** — Collection, environment, and global variables with `{{syntax}}`, autocomplete, and Keychain-backed secrets
- **Authentication** — Bearer token, Basic auth, custom headers, client certificates (mTLS)
- **Code Generation** — 14 generator variants across cURL, Python, JavaScript, Swift, Go, Ruby, PHP, and Java
- **Import** — Postman v2.1, Insomnia v4, OpenAPI 3.x / Swagger 2.0, and cURL commands
- **iCloud Sync** — Private CloudKit sync across all your Macs
- **Assertions & Extractors** — Declarative response tests and variable extraction from JSON paths
- **Performance** — < 500ms launch, < 50ms request overhead, < 100MB idle memory

### System Requirements

- macOS 14 Sonoma or later
- Apple Silicon or Intel
